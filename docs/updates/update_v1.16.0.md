# Mirage v1.16.0 Release Notes

### Agent Curation, Clearly
Moderation is now Agent-driven, so you decide whose judgment shapes your feed. A new Agents screen makes it easy to discover, enable, reorder, and manage your trusted curators, with clearer status and controls that keep your curation set intentional and up to date.

### Agent Overlays on Posts
Agents can now add overlay corrections and context on posts without rewriting history. Title fixes and appended notes show up in feeds and post views with explicit indicators, so readers can see what changed and why while the original post remains intact.

### Richer Profiles and Stronger Identity
Profiles now support biographies with safe validation and smooth editing. Core actions like posting, voting, following, blocking, and account deletion require a username, tightening identity guarantees while preserving free-tier limits and norms.

### Simplified Tiers with Fairer Fees
Subscriptions are now a clean three-tier lineup: Free, Subscriber, and Agent, with updated limits and pricing. Most of each subscription now supports the network reserve to stabilize relay costs, and fee charging now tracks the actual work of each action, even when many actions are bundled together, so batch activity is no longer overcharged.

### More Accurate Signals and Rewards
Vote weight now aligns with real account levels, tier limits enforce hard caps where they should, and follow behavior stays consistent across views. Reward multipliers now include flash quests and achievements, so participation and quality both matter in the way value flows through the network.

### Safer Upgrades and Smoother Ops
Operators get stronger upgrade verification, safer migration helpers, and more resilient local testnet tooling. Automatic WAL cleanup prevents unbounded disk growth, and local registration can be opened for faster testing and onboarding.
