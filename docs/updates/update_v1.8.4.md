# Mirage v1.8.4 Release Notes

### Overview

Mirage is entering private beta. Starting with this release, new account creation requires an invite code from an existing user. This isn't about exclusivity — it's about building something that works before opening the floodgates.

Every decentralized platform faces the same challenge: how do you build genuine community when bots and bad actors can create unlimited accounts for free? Most platforms solve this with phone verification, government ID, or centralized moderation—all antithetical to what decentralization promises. We're taking a different approach. During beta, growth happens through trust networks. Each user can invite others they vouch for, creating natural accountability without sacrificing privacy or decentralization.

This release also introduces subscriber identity. Users with active subscriptions (Trusted, Established, Distinguished) now have their usernames displayed in their tier color throughout the platform. It's a small visual signal that helps the community recognize members who've chosen to support Mirage's development.

---

### Private Beta (Invite-Only Access)

- New account creation requires a valid invite code
- Existing users receive invite codes to share
- Invite codes are single-use and tied to the inviter
- No changes for existing accounts—you're already in

---

### Subscriber Identity

- Usernames now display in tier colors for subscribers (level 1-3)
- Trusted (level 1): Blue
- Established (level 2): Purple  
- Distinguished (level 3): Gold
- Admins (level 100+): Red
- Free users retain default theme colors
- Applies to post feeds, comments, and post view pages
