# Mirage Roadmap

This roadmap is intentionally high-level. It is safe to share publicly and avoids internal implementation notes, credentials, and operator-only details.

### Now

- Improve onboarding and account recovery UX
- Reduce spam and abuse without adding friction for legitimate users
- Tighten performance on feeds, comments, and indexing

### Next

- Mobile apps (iOS and Android) with parity on core reading and posting flows
- Better discovery, topic search, and follow recommendations
- More transparent moderation tooling and user-controlled filters

### Later

- Sustainable incentives for node operators based on uptime and service quality
- More advanced governance and parameter tuning as the network grows
- Optional ecosystem integrations (clients, indexers, explorers)

### Security note

Do not store mnemonics, private keys, funded test accounts, or production runbooks in `/docs`. Keep secrets in a password manager or a private vault.
