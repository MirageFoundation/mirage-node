# Blockchain Security Review (Basic)

Date: 2026-02-16
Scope: `blockchain/` (core module, ante handlers, bridge, orchestrator)
Out of scope: `web/`, `indexer/`, `deploy/`, external chain programs

## Summary
- No actionable security issues found in this basic pass.
- Two items are confirmed as intended design (indexer-enforced deletes, devnet-only bridge).
- Relay CheckTx now enforces min-gas-prices (no mempool reliance).

## Design assumptions confirmed (not issues)
- Delete authorization is enforced by the indexer by design. The chain is a pass-through
  for messages, and indexers must apply ownership rules for `MsgDelete`.
- Bridge is devnet-only and not marketed; validator-attested mint confirmations are
  acceptable for this non-production usage.

## Operational notes
- Relay CheckTx enforces min-gas-prices; mempool config remains a tuning knob for local load.

## Controls observed
- Envelope signature verification with canonical serialization per message.
- Envelope timestamp bounds (`MaxEnvelopeAge`) for replay protection.
- PoW validation with dynamic difficulty and recent block-hash window.
- Governance-only authority checks for sensitive operations (params, mint/burn, punish).
- Bridge validation: enabled chain list, destination address format, sequence gating,
  bonded validator checks, power threshold.

## Tests added in this pass
- Reject mismatched `envelope_pubkey` for `SetUsername` and `SendTokens`.
- Reject unbonded validator for `BridgeAttestBurned`.
- Reject `burn_id` above current sequence for `BridgeAttestMinted`.
- Reject relay txs below min-gas-prices (unit + local testnet).
- Reject relay txs with invalid signatures (local testnet).
- Reject relay txs with invalid PoW (local testnet).
- Reject relay txs with stale envelope timestamps (local testnet).

## Follow-ups (optional)
- If Delete/indexer authorization model changes, add explicit tests to match new policy.
